## Safety boundary and authority

This document consolidates the reviewed, value-free results from SEC-001A,
SEC-001B, and SEC-001C. It contains path aliases, path patterns, key and
environment-variable names, source readers and writers, generalized permission
classes, classifications, and dispositions only. It contains no file contents,
matching lines, credential values, environment values, personal-data values,
household names, device identifiers, account names, or absolute home paths.

The exhaustive persisted-field allowlists remain in
`SEC-001A_REPOSITORY_SOURCE_INVENTORY.md` under **Reviewed persisted fields**.
The key-family cells below incorporate those reviewed rows by reference; they
do not authorize unlisted dynamic or pass-through fields.

The private SEC-001B and SEC-001C collector reports remain outside the source
repository under `<data-root>/audit/`. Their directories are mode `0700` and
their files are mode `0600`. The committed SEC-001A through SEC-001D reviews
contain sanitized conclusions only.

## Destination conventions

| Destination | Proposed use |
| --- | --- |
| `<state-root>` | Durable non-secret state: `<data-root>/state` for the current per-user deployment, `/var/lib/kotibot` for a Linux service, and the KotiBot application-data root under `%PROGRAMDATA%` for a Windows service. |
| `<credential-root>` | systemd `LoadCredential` or protected `/etc/kotibot/credentials.d/` files selected by SEC-002; never the source tree or durable-state JSON. |
| `<config-root>` | Protected non-secret service configuration under `/etc/kotibot/`, with a platform-specific equivalent outside the installed code. |
| `<cache-root>` | Replaceable cache under `/var/cache/kotibot` or the platform per-user cache root. |
| `<runtime-root>` | Short-lived service runtime data under `/run/kotibot` or the platform runtime root. |
| `<log-root>` | Bounded application and audit logs under `/var/log/kotibot` or a protected per-user log root. |
| `<media-root>` | Protected recordings under `<state-root>/media/recordings`, unless an explicitly configured external protected media root is selected. |
| `<package-root>` | Read-only Android package distribution outside the development checkout. |
