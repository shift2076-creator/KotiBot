Set up the new phone

  1. Admin, from unrelenting: connect the phone over USB and allow USB debugging. The phone must be listed as a device, not unauthorized.
  2. Admin: install the approved apps with the sync helper. Only admin-approved releases, one phone per run.
  3. New person: install pivault-root.crt as a CA certificate. See PiVault Certificate in Settings.
  4. New person, Firefox: open About Firefox, tap the logo five times, open Secret Settings, turn on "Use third party CA certificates", and restart Firefox. If the switch is missing, use Chrome.
  5. New person, Bitwarden app: choose the self-hosted region, enter https://192.168.4.90:8448 as the server, and sign in with the account created for them.

Delete the sync helper after each run. It holds a sign-in token that expires in two hours.
